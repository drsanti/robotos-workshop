# robotos Workshop — Ebook

Generated HTML curriculum from:

- **Chapters:** `docs/ebook/chapters/ch*.md` (canonical long-form)
- **Lab sheets:** `labs/{mw,wh,hw}/*/README.md`

**Markdown remains the source of truth** — do not hand-edit `src/chapters/` or
`src/generated/`.

## Open (students)

Double-click **[book/index.html](book/index.html)** (works offline via `file://`).

## Rebuild (maintainers)

Requires [`mdbook`](https://rust-lang.github.io/mdBook/) on PATH
(`cargo install mdbook`):

```powershell
pwsh -File .\ebook\scripts\build.ps1
```

This:

1. Stages chapters → `src/chapters/`
2. Stages lab sheets → `src/generated/{mw,wh,hw}/` + regenerates `src/SUMMARY.md`
3. Downloads `theme/mermaid.min.js` if missing (offline Mermaid)
4. Runs `mdbook build` → `book/`

Mermaid lint (also runs inside `build.ps1` — blocks Mermaid 11 “Syntax error” bombs):

```powershell
pwsh -File .\ebook\scripts\check-mermaid.ps1
```

Smoke / coverage:

```powershell
pwsh -File .\ebook\scripts\smoke.ps1
```

Agent skill: `workshop-ebook` (personal + `.cursor/skills/`). Rule:
`.cursor/rules/workshop-ebook-mermaid.mdc`.

## Layout

| Path | Role |
|------|------|
| `src/introduction.md`, `reading-order.md` | Curated front matter |
| `src/tracks/*.md` | Track hubs (MW / WH; HW hub staged from `labs/hw/README.md`) |
| `src/chapters/` | Staged ebook chapters (build output of stage script) |
| `src/generated/` | Staged **all** lab sheets + labs index + `common` + CHECKLISTs |
| `src/SUMMARY.md` | Sidebar TOC (regenerated by stage) |
| `theme/ebook.css`, `ebook.js` | Workshop look + Mermaid bootstrap |
| `book/` | HTML site (commit after rebuild for class drop) |
