# Special workshops

Stand-alone workshops that sit **beside** the main MW → WH → HW tracks.
They are not part of the main lab order (`scripts/run list`,
[`docs/lab-outline.md`](../docs/lab-outline.md)). The instructor decides
when to run one.

| Folder | Workshop | Needs from the main tracks |
|--------|----------|----------------------------|
| [`ai-coding/`](ai-coding/) | **AI Coding Assistance**: LLM basics, prompting, AGENTS.md / CLAUDE.md, rules, SKILL.md, subagents, MCP, hooks, plugins, safe use | MW-00/01 + WH-00…02 |

Each special workshop has its own README, theory cards, labs and handouts
inside its folder. Nothing in here changes the main labs.
