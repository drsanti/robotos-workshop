---------------------------------------------------------------------------
A) Middleware / warehouse (no board)
---------------------------------------------------------------------------
Env (optional TCP peer):
  $env:ROBOTOS_CONNECT = "tcp/127.0.0.1:7447"

Sim (WH labs):
  Start-Process .\code\robotos-sim-v0.1.0-windows-x64\robotos-sim.exe
  (or double-click robotos-sim.exe). Auto External+Native+Connect.

Python:
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install -U pip
  python -m pip install .\code\robotos-0.3.0-py3-none-win_amd64.whl

PATH (each new terminal):
  $env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"

Smoke:
  robotos topic list
  python labs\wh\wh-01-drive-twist\starter\drive_forward.py

---------------------------------------------------------------------------
B) ESP32-S3 board (HW labs) — serial-bridge
---------------------------------------------------------------------------
Prereq: board flashed; USB attached.

1) Terminal A — bridge (leave open):
     cd <robotos-workshop>
     $env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"
     $env:ROBOTOS_LISTEN = "tcp/0.0.0.0:7447"
     serial-bridge --port auto --baud 921600 --robot-id 01 --cmd-topic all
   Or pin: --port COM7
   List: Get-CimInstance Win32_SerialPort | Select-Object DeviceID,Name

2) Terminal B — labs:
     cd <robotos-workshop>
     $env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"
     $env:ROBOTOS_CONNECT = "tcp/127.0.0.1:7447"
     .\.venv\Scripts\Activate.ps1
     robotos topic echo /robot/01/sys/board --count 3
     python labs\hw\hw-01-caps-probe\starter\caps_probe.py

Troubleshooting:
  - Port busy → close serial monitor / other bridge
  - no topics → bridge down or ROBOTOS_CONNECT missing
  - Actuator no-op → forgot --cmd-topic all
  - ExecutionPolicy on Activate.ps1 → Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
