robotos-workshop pack
=====================
Date:       2026-11-02
OS/arch:    macos-arm64
robotos:    v0.3.0
robotos-sim: code/robotos-sim-v0.1.0-macos-arm64/robotos-sim.app
serial-bridge: code/robotos-v0.3.0-macos-arm64/bin/serial-bridge
Contract:   P0 warehouse 2026-11-02 + HW board labs

Prefer helpers under scripts/. Full SETUP: SETUP.md · Ebook: docs/ebook/chapters/ch00-setup-your-machine.md

---------------------------------------------------------------------------
A) Fast path (recommended)
---------------------------------------------------------------------------
1) Once: ./scripts/start-here.sh
   (or double-click scripts/start-here.command)
2) Smoke:
     robotos topic list
     ./scripts/run wh-01
3) Board labs: ./scripts/start-bridge.sh in a second Terminal, then
     ./scripts/run hw-01

List labs:  ./scripts/run list

---------------------------------------------------------------------------
B) Manual Terminal (optional)
---------------------------------------------------------------------------
Env (optional TCP peer):
  export ROBOTOS_CONNECT=tcp/127.0.0.1:7447

PATH (each new terminal):
  export PATH="$PWD/code/robotos-v0.3.0-macos-arm64/bin:$PATH"
  chmod +x code/robotos-v0.3.0-macos-arm64/bin/* 2>/dev/null || true

Sim — first launch: Finder → right-click → Open (Gatekeeper):
  open code/robotos-sim-v0.1.0-macos-arm64/robotos-sim.app
  Auto External+Native+Connect. If blocked: System Settings → Privacy & Security → Allow.

Python:
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -U pip
  python -m pip install code/robotos-0.3.0-py3-none-any.whl

Smoke:
  robotos topic list
  ./scripts/run wh-01

---------------------------------------------------------------------------
C) ESP32-S3 board — serial-bridge
---------------------------------------------------------------------------
1) Prefer: ./scripts/start-bridge.sh
   Or: serial-bridge --port /dev/cu.usbmodemXXXX --baud 921600 --robot-id 01 --cmd-topic all

2) Labs:
     export ROBOTOS_CONNECT=tcp/127.0.0.1:7447
     source .venv/bin/activate
     ./scripts/run hw-01

Troubleshooting:
  - Gatekeeper blocks sim → right-click Open / Privacy & Security Allow
  - Port busy → close serial monitor
  - no topics → bridge down or ROBOTOS_CONNECT missing
  - chmod +x after unzip if binaries refuse to run

Support:
  instructor
