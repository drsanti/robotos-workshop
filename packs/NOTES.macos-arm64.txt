---------------------------------------------------------------------------
A) Middleware / warehouse (no board)
---------------------------------------------------------------------------
Env (optional TCP peer):
  export ROBOTOS_CONNECT=tcp/127.0.0.1:7447

PATH (each new terminal):
  export PATH="$PWD/code/robotos-v0.3.0-macos-arm64/bin:$PATH"
  chmod +x code/robotos-v0.3.0-macos-arm64/bin/robotos \
           code/robotos-v0.3.0-macos-arm64/bin/serial-bridge 2>/dev/null || true

Sim (WH labs) — first launch: Finder → right-click → Open (Gatekeeper):
  chmod +x code/robotos-sim-v0.1.0-macos-arm64/robotos-sim 2>/dev/null || true
  open code/robotos-sim-v0.1.0-macos-arm64/robotos-sim.app
  # or: ./code/robotos-sim-v0.1.0-macos-arm64/robotos-sim
  Auto External+Native+Connect. If blocked: System Settings → Privacy & Security → Allow.

Python:
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -U pip
  python -m pip install code/robotos-0.3.0-*-macosx*.whl
  # or: code/robotos-0.3.0-py3-none-any.whl if that is what this pack ships

Smoke:
  robotos topic list
  python labs/wh/wh-01-drive-twist/starter/drive_forward.py

---------------------------------------------------------------------------
B) ESP32-S3 board (HW labs) — serial-bridge
---------------------------------------------------------------------------
Prereq: board flashed; USB attached.

1) Terminal A — bridge (leave open):
     cd <robotos-workshop>
     export PATH="$PWD/code/robotos-v0.3.0-macos-arm64/bin:$PATH"
     export ROBOTOS_LISTEN=tcp/0.0.0.0:7447
     chmod +x code/robotos-v0.3.0-macos-arm64/bin/serial-bridge 2>/dev/null || true
     serial-bridge --port auto --baud 921600 --robot-id 01 --cmd-topic all
   Or pin: --port /dev/cu.usbmodemXXXX  (tab-complete: ls /dev/cu.usbmodem*)

2) Terminal B — labs:
     cd <robotos-workshop>
     export PATH="$PWD/code/robotos-v0.3.0-macos-arm64/bin:$PATH"
     export ROBOTOS_CONNECT=tcp/127.0.0.1:7447
     source .venv/bin/activate
     robotos topic echo /robot/01/sys/board --count 3
     python labs/hw/hw-01-caps-probe/starter/caps_probe.py

Troubleshooting:
  - no topics → bridge down or ROBOTOS_CONNECT missing
  - Actuator no-op → forgot --cmd-topic all
  - Zip stripped +x → chmod +x the binaries again
