B) Manual Terminal (optional)
---------------------------------------------------------------------------
Env (optional TCP peer):
  export ROBOTOS_CONNECT=tcp/127.0.0.1:7447

PATH (each new terminal):
  export PATH="$PWD/code/robotos-v0.3.0-macos-arm64/bin:$PATH"
  chmod +x code/robotos-v0.3.0-macos-arm64/bin/* 2>/dev/null || true

Sim — first launch: Finder → right-click → Open (Gatekeeper):
  open code/robotos-sim-v0.1.0-macos-arm64/robotos-sim.app
  Auto External+Native+Connect. If blocked: System Settings → Privacy & Security → Allow.

Python:
  python3 -m venv .venv
  source .venv/bin/activate
  python -m pip install -U pip
  python -m pip install code/robotos-0.3.0-py3-none-any.whl

Smoke:
  # Sim must LISTEN on :7447 (UI “connected” alone is not enough):
  #   export ROBOTOS_LISTEN=tcp/0.0.0.0:7447
  #   open code/robotos-sim-v0.1.0-macos-arm64/robotos-sim.app
  # Labs window: unset ROBOTOS_LISTEN; export ROBOTOS_CONNECT=tcp/127.0.0.1:7447
  robotos topic list
  ./scripts/run wh-01

---------------------------------------------------------------------------
C) ESP32-S3 board — serial-bridge
---------------------------------------------------------------------------
Boards: es3c28p (LED+mic, caps~0x33) | ws28p (IMU+RTC, caps~0x3c, no LED/mic)
Flash: fw/{es3c28p|ws28p}/ — see fw/README.md (esptool + "@flash_args")
Always run HW-01 and follow caps (labs/hw/README.md).

1) Prefer: ./scripts/start-bridge.sh
   (uses --port auto; close warehouse sim first to free :7447)
   Or: serial-bridge --port auto --baud 921600 --robot-id 01 --cmd-topic all \
         --probe-settle-ms 2000 --probe-ms 5000
   Pin the path from "[auto] selected". cu.usbmodem* can be skipped
   (no workshop frame in 2500 ms) while tty.usbmodem* is the board.
   This Mac: --port /dev/tty.usbmodem101

2) Labs:
     export ROBOTOS_CONNECT=tcp/127.0.0.1:7447
     source .venv/bin/activate
     ./scripts/run hw-01

Troubleshooting:
  - Gatekeeper blocks sim → right-click Open / Privacy & Security Allow
  - Port busy → close serial monitor
  - no topics → bridge down or ROBOTOS_CONNECT missing
  - chmod +x after unzip if binaries refuse to run
  - Teaching lock on in sim hides Mock/WS bridge — WH Native path uses Native + Join graph
