robotos-workshop pack
=====================
Date:       2026-11-02
OS/arch:    windows-x64
robotos:    v0.3.0
robotos-sim: code/robotos-sim-v0.1.0-windows-x64/robotos-sim.exe
serial-bridge: code/robotos-v0.3.0-windows-x64/bin/serial-bridge.exe
Contract:   P0 warehouse 2026-11-02 + HW board labs

Open this folder in **VS Code**. Prefer helpers under scripts\ (not Git Bash —
it rewrites /robot/... paths).

Full SETUP: SETUP.md · Ebook: docs/ebook/chapters/ch00-setup-your-machine.md

---------------------------------------------------------------------------
A) Fast path (recommended)
---------------------------------------------------------------------------
1) Once: double-click  scripts\start-here.cmd
   (creates .venv, installs wheel, starts sim)
2) VS Code → Terminal → New Terminal
3) Smoke:
     robotos topic list
     scripts\run.cmd wh-01
4) Board labs: double-click scripts\start-bridge.cmd (leave open), then
     scripts\run.cmd hw-01

List labs:  scripts\run.cmd list

---------------------------------------------------------------------------
B) Manual PowerShell (optional)
---------------------------------------------------------------------------
Env (optional TCP peer):
  $env:ROBOTOS_CONNECT = "tcp/127.0.0.1:7447"

PATH (each new PowerShell — skip in VS Code terminal):
  $env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"

Sim:
  Start-Process .\code\robotos-sim-v0.1.0-windows-x64\robotos-sim.exe

Python:
  python -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install -U pip
  python -m pip install .\code\robotos-0.3.0-py3-none-win_amd64.whl

Smoke:
  robotos topic list
  scripts\run.cmd wh-01
  # or: python labs\wh\wh-01-drive-twist\starter\drive_forward.py

---------------------------------------------------------------------------
C) ESP32-S3 board — serial-bridge
---------------------------------------------------------------------------
Prereq: board flashed; USB attached.

1) Prefer: scripts\start-bridge.cmd
   Or pin port: serial-bridge --port COM17 --baud 921600 --robot-id 01 --cmd-topic all
   List: Get-CimInstance Win32_SerialPort | Select-Object DeviceID,Name
   If --port auto skips USB: --probe-settle-ms 2000 --probe-ms 5000

2) Labs terminal (VS Code or start-here):
     $env:ROBOTOS_CONNECT = "tcp/127.0.0.1:7447"
     scripts\run.cmd hw-01

Troubleshooting:
  - Port busy → close serial monitor / other bridge
  - no topics → bridge down or ROBOTOS_CONNECT missing
  - Actuator no-op → forgot --cmd-topic all
  - ExecutionPolicy on Activate.ps1 → Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
