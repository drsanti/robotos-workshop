C) ESP32-S3 board (HW labs) — serial-bridge
---------------------------------------------------------------------------
Boards: es3c28p (LED+mic, caps~0x33) | ws28p (IMU+RTC, caps~0x3c, no LED/mic)
Flash: fw/{es3c28p|ws28p}/ — see fw/README.md (esptool + "@flash_args")
Always run HW-01 and follow caps (labs/hw/README.md).

Prereq: board flashed; USB attached.
Serial permission: sudo usermod -aG dialout $USER  then log out/in.
Self-check: groups | grep dialout ; ls -l /dev/ttyACM*
Do not sudo serial-bridge to paper over permissions.

1) Terminal A — bridge (leave open):
     ./scripts/start-bridge.sh
   Or manual:
     cd <robotos-workshop>
     export PATH="$PWD/code/robotos-v0.3.0-linux-x64/bin:$PATH"
     export ROBOTOS_LISTEN=tcp/0.0.0.0:7447
     chmod +x code/robotos-v0.3.0-linux-x64/bin/serial-bridge 2>/dev/null || true
     serial-bridge --port auto --baud 921600 --robot-id 01 --cmd-topic all
   Or pin: --port /dev/ttyACM0

2) Terminal B — labs:
     cd <robotos-workshop>
     export PATH="$PWD/code/robotos-v0.3.0-linux-x64/bin:$PATH"
     export ROBOTOS_CONNECT=tcp/127.0.0.1:7447
     source .venv/bin/activate
     robotos topic echo /robot/01/sys/board --count 3
     ./scripts/run hw-01
     # or: python labs/hw/hw-01-caps-probe/starter/caps_probe.py

Troubleshooting:
  - Permission denied on /dev/ttyACM* → dialout + re-login
  - no topics → bridge down or ROBOTOS_CONNECT missing
  - Actuator no-op → forgot --cmd-topic all
  - Zip stripped +x → chmod +x the binaries again
