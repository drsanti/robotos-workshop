Windows

Use PowerShell. Stay in this track until the end.

ใช้ PowerShell อยู่กับแทร็กนี้จนจบ

Use PowerShell. Press the Win key, type PowerShell, and press Enter. Stay in this section until you are done.

ใช้ PowerShell กดปุ่ม Win พิมพ์ PowerShell แล้วกด Enter อยู่กับส่วนนี้จนจบ

powershell
cd YOUR_WORKSHOP_DIR
$env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"
Get-Command robotos
robotos version

Expect robotos 0.3.0 (any 0.3.x is fine).

ควรได้ robotos 0.3.0 (เวอร์ชัน 0.3.x ก็ใช้ได้)

Once per machine you can double-click scripts/start-here.cmd. That creates .venv, installs the wheel, and starts the sim. The next PowerShell window is still blank. Paste the blocks below again.

ครั้งแรกต่อเครื่อง สามารถดับเบิลคลิก scripts/start-here.cmd ได้ จะสร้าง .venv ติดตั้ง wheel และเปิด sim แต่ PowerShell หน้าต่างถัดไปยังว่างอยู่ ต้องวางบล็อกด้านล่างอีกครั้ง

Python 3.10 or newer, from python.org. Tick Add python.exe to PATH during install.

ใช้ Python 3.10 ขึ้นไป จาก python.org ตอนติดตั้งให้ติ๊ก Add python.exe to PATH

powershell
cd YOUR_WORKSHOP_DIR
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install .\code\robotos-0.3.0-py3-none-win_amd64.whl
python -c "import robotos; print(robotos.Node.version())"

If .venv already exists, start at .\.venv\Scripts\Activate.ps1. The prompt should show (.venv).

ถ้ามี .venv อยู่แล้ว ให้เริ่มที่ .\.venv\Scripts\Activate.ps1 พรอมต์ควรขึ้น (.venv)

If Activate.ps1 is blocked, run this once, then activate again:

ถ้า Activate.ps1 ถูกบล็อก ให้รันคำสั่งนี้ครั้งเดียว แล้ว activate อีกครั้ง:

powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

If the wheel name differs, run Get-ChildItem .\code\*.whl and install that file. Use the win_amd64 wheel.

ถ้าชื่อ wheel ไม่ตรง ให้รัน Get-ChildItem .\code\*.whl แล้วติดตั้งไฟล์นั้น ใช้ wheel แบบ win_amd64

WH labs need the sim. MW and HW do not.

แล็บ WH ต้องใช้ sim ส่วน MW และ HW ไม่จำเป็น

powershell
cd YOUR_WORKSHOP_DIR
Start-Process .\code\robotos-sim-v0.1.0-windows-x64\robotos-sim.exe

Or double-click robotos-sim.exe in that folder. Confirm the window says connected / NATIVE. If it does not: Warehouse → Native → External → Connect. Graded WH labs use Native, not Mock. Do not restart the sim every time you open PowerShell.

หรือดับเบิลคลิก robotos-sim.exe ในโฟลเดอร์นั้น ตรวจว่าหน้าต่างขึ้น connected / NATIVE ถ้าไม่ใช่: Warehouse → Native → External → Connect แล็บ WH ที่ให้คะแนนใช้ Native ไม่ใช่ Mock อย่ารีสตาร์ท sim ทุกครั้งที่เปิด PowerShell

The sim must already be connected.

sim ต้องเชื่อมต่อไว้แล้ว

powershell
cd YOUR_WORKSHOP_DIR
$env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"
.\.venv\Scripts\Activate.ps1
robotos topic list
scripts\run.cmd wh-01

topic list shows /robot/01/cmd_vel, /robot/01/odom, and /robot/01/scan. WH-01 moves the robot about 1 m. Use PowerShell for these commands. Git Bash rewrites paths that start with /robot/.

topic list ควรเห็น /robot/01/cmd_vel, /robot/01/odom และ /robot/01/scan WH-01 จะขยับหุ่นยนต์ประมาณ 1 ม. ใช้ PowerShell สำหรับคำสั่งเหล่านี้ Git Bash จะแปลง path ที่ขึ้นต้นด้วย /robot/

Optional, same window:

ทางเลือก ใช้หน้าต่างเดิม:

powershell
robotos topic echo /robot/01/odom --count 5

Close the sim first. Two windows.

ปิด sim ก่อน ใช้สองหน้าต่าง

Window A — bridge. Leave it open. Or double-click scripts/start-bridge.cmd.

หน้าต่าง A — bridge เปิดค้างไว้ หรือดับเบิลคลิก scripts/start-bridge.cmd

powershell
cd YOUR_WORKSHOP_DIR
$env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"
$env:ROBOTOS_LISTEN = "tcp/0.0.0.0:7447"
serial-bridge --port auto --baud 921600 --robot-id 01 --cmd-topic all

If auto-detect misses the USB port, add --probe-settle-ms 2000 --probe-ms 5000, or set --port COM17 to the COM port shown in Device Manager. serial-bridge.exe is next to robotos.exe.

ถ้า auto-detect พลาดพอร์ต USB ให้เพิ่ม --probe-settle-ms 2000 --probe-ms 5000 หรือตั้ง --port COM17 ตาม COM ใน Device Manager serial-bridge.exe อยู่ข้าง robotos.exe

Window B — labs. A second PowerShell. Do not reuse window A.

หน้าต่าง B — แล็บ เปิด PowerShell ใหม่ อย่าใช้หน้าต่าง A ซ้ำ

powershell
cd YOUR_WORKSHOP_DIR
$env:PATH = "$PWD\code\robotos-v0.3.0-windows-x64\bin;$env:PATH"
Remove-Item Env:ROBOTOS_LISTEN -ErrorAction SilentlyContinue
$env:ROBOTOS_CONNECT = "tcp/127.0.0.1:7447"
.\.venv\Scripts\Activate.ps1
robotos topic echo /robot/01/sys/board --count 3
scripts\run.cmd hw-01

Run HW-01 before LED or IMU labs. Follow the caps it prints.

รัน HW-01 ก่อนแล็บ LED หรือ IMU แล้วทำตาม caps ที่พิมพ์ออกมา
